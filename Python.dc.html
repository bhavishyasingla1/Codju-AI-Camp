CURRICULUM SPECIFICATION

5-Module Curriculum

From syntax basics to problem-solving capstone projects.

Module 1: Basics & Syntax Foundations

Sessions 1 & 2

Write your first line of Python code. Master variables, numeric and string data types, user input prompting, f-strings, arithmetic calculations, and terminal print formatting.

  • ✓Python syntax, indentation rules & IDE setup
  • ✓Data types: int, float, str, bool
  • ✓Capturing input with input() & typecasting
  • ✓Formatted f-strings & arithmetic operators

Module 2: Decision Making & Conditional Logic

Sessions 3 & 4

Teach code to make intelligent decisions. Understand boolean expressions, comparison operators (==, !=, >, <), logical operators (and, or, not), and multi-branch if / elif / else trees.

  • ✓Comparison & truth table evaluations
  • ✓Single and nested if-elif-else statements
  • ✓Logical compound operators (and, or, not)
  • ✓Input validation and graceful error checking

Module 3: Loops & Data Collections

Sessions 5, 6 & 7

Automate repetitive computing! Master for loops with range(), condition-controlled while loops, list manipulations (indexing, slicing, append, pop), and key-value dictionaries.

  • ✓Definite iteration: for item in list
  • ✓Indefinite iteration: while condition:
  • ✓List methods: .append(), .sort(), .remove()
  • ✓Key-value mapping with Python Dictionaries

Module 4: Modular Functions & Standard Libraries

Sessions 8, 9 & 10

Write DRY (Don't Repeat Yourself) clean code. Define custom functions with def, pass parameters, return calculated results, understand variable scope, and import Python's random, math, and time libraries.

  • ✓Defining reusable functions with arguments & return
  • ✓Global vs local variable scope
  • ✓Standard library imports: random, math, time
  • ✓File I/O: Reading and writing text files

Module 5: Problem Solving & Capstone Demo

Sessions 11 & 12

Synthesize all skills into a standalone capstone application. Conduct live code reviews, practice algorithmic optimization, handle edge cases, and present during the final Codju graduation showcase.

  • ✓Algorithmic debugging strategies
  • ✓Handling runtime exceptions with try / except
  • ✓Code refactoring and PEP 8 style standards
  • ✓Capstone project presentation & certification
