Week 1: HTML Foundations & Semantics

Learn how the web works. Structure documents with headings, paragraphs, multimedia tags, hyperlinks, and semantic containers.

  • ✓ Tags, elements, and attributes
  • ✓ Hyperlinks & navigation anchors
  • ✓ Embedding images & videos

Week 2: CSS Box Model & Visual Styling

Bring pages to life with color theory, Google Fonts typography, borders, margins, padding, and CSS selectors.

  • ✓ Margins, padding, and borders

Master the layout engine used by modern websites like Apple and Netflix. Build responsive navigation bars and multi-column grids.

Make sites adapt flawlessly to any screen size. Add smooth button hover animations, transitions, and mobile menu styling.

  • ✓ Media queries for mobile & tablet
  • ✓ CSS transitions and hover states
  • ✓ Drop shadows and modern cards
  • ✓ Cross-browser inspection tools
