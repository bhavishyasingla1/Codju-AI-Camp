# Codju Winter CodeFest ❄️

Welcome to the **Codju Winter CodeFest** repository. This is the official high-conversion landing page for Codju's flagship 1-month live winter coding camp starting post-Diwali.

---

## 🌟 Overview

Codju Winter CodeFest is an outcome-driven coding & AI camp delivered **100% Live on YouTube** open to **All Grades (Grades 1–10)** across 1 unified learning path:

1. **🎬 Session 1: Scratch Jr** — Early visual storytelling & interactive animated storybooks.
2. **🕹️ Session 2: Scratch** — Logic, coordinates, and custom playable arcade games.
3. **🐍 Session 3: Python** — Real syntax, computational logic, text RPGs, and utility tools.
4. **🤖 Session 4: Building with AI** — Prompt engineering, generative media, custom AI assistants, and rapid prototyping.
5. **🏆 Session 5: Capstone Day** — Project showcase, QR-verified certificate, and permanent public Codju Student Profile.

---

## 🚀 Key Value Propositions

- **100% Live on YouTube:** Accessible from Smart TVs, iPads, tablets, or laptops without Zoom app installs, password barriers, or lag.
- **1 Tangible Capstone Project per Track:** Every child builds, tests, and publishes a real game, animation, Python project, or AI tool.
- **🌟 Public Codju Student Profile:** Every graduate receives a personal, permanent digital portfolio link (`codju.com/student/name`) showcasing their verified skill badges, capstone project, and credentials.
- **📜 Verified Certificate of Achievement:** Authenticated digital certificate with QR verification co-branded with their school.
- **🏫 Free for Codju Partner Schools:** 100% sponsored scholarships for students studying in partner schools.
- **₹999 Flat Public Fee:** An irresistible, all-inclusive price point for non-partner school enrollments.
