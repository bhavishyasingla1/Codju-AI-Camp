# Codju Academy 🎓✨

Welcome to the **Codju Academy** repository. This project contains the complete high-converting web presence and self-contained Design Components (`.dc.html`) for Codju Academy's 5 specialized coding tracks and the flagship AI Winter Camp.

## 🎨 Shared Design System

- **Typography:** Apple system font stack (`-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", "Segoe UI", Roboto, Helvetica, Arial, sans-serif`)
- **Brand Colors:**
  - Deep Purple: `#2c0a78`
  - Vibrant Purple: `#7c3aed`
  - Cream Background: `#fdf9f3`
  - Warm Accent / Gold: `#f7d56a`
- **Component Architecture:**
  - Every page is completely self-contained as a `.dc.html` file with embedded CSS and vanilla JS for zero-dependency portability.
  - Standard `.html` aliases are provided for frictionless hosting on GitHub Pages, Cloudflare Pages, Vercel, or Netlify.

## 🏃 Local Preview

No build step or Node packages required! Built with lightweight, ultra-fast web standards:
1. Double click any `.dc.html` or `.html` file to preview directly in your browser.
2. Or run a local static server:
   ```bash
   npx -y serve ./
   ```
