# Codju Winter Fest ❄️

Welcome to the **Codju Winter Fest** repository. This is the official high-conversion landing page for Codju's flagship 1-month live winter coding camp.

---

## 🌟 Overview

**Codju Winter Fest** is an outcome-driven coding & AI camp delivered **100% Live on YouTube** open to **Grades 1–10** across 4 creative learning areas:

1. **🎬 Stage 01: ScratchJr** — Animate Your Stories: Create animated scenes using characters, movement and sound. (*Project: Animated Story*)
2. **🕹️ Stage 02: Scratch** — Design a Game: Explore game logic, movement, scoring and interactions. (*Project: 2D Arcade Game*)
3. **🐍 Stage 03: Python** — Write Real Code: Discover variables, conditions, loops and basic programming logic. (*Project: Interactive Python Adventure*)
4. **🤖 Stage 04: AI** — Create With AI: Explore AI-assisted ideas, visuals, dialogue and creative content. (*Project: AI-Assisted Creation*)

---

## 🚀 Key Value Propositions

- **Turn Screen Time Into Creation Time:** Guided weekend live sessions on YouTube with instant replay access.
- **Hands-On Project in Every Area:** Students build real animations, games, Python adventures, and AI tools.
- **🌟 Public Codju Student Profile:** Every graduate receives a personal, permanent digital portfolio link (`codju.com/student/name`) showcasing completed projects and verified badges.
- **📜 Verified Certificate of Achievement:** Authenticated digital certificate with QR verification co-branded with their school.
- **🏫 Free for Codju Partner Schools:** 100% free scholarships for students studying in eligible partner schools.
- **₹999 Flat Public Pass:** An accessible, all-inclusive price point for open enrollments.
