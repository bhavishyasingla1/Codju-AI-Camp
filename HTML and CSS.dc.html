5-Week Curriculum

A progressive front-end journey from blank text document to live web application deployment.

Week 1: Semantic HTML5 Structure & Page Skeleton

Construct clean semantic page markup using headings, paragraphs, lists, anchor hyperlinks, and optimized images.

Sessions 1 & 2

✓ Semantic elements: <header>, <main>, <section>, <footer>
✓ Image embedding with alt text and responsive widths
✓ Hyperlinks (<a href>) and relative page paths

Module Project: Personal Creator Bio & Profile Page

Week 2: CSS Styling, Typography & The Box Model

Style pages with modern Google Fonts, custom color palettes, borders, margins, padding, and box-sizing.

Sessions 3 & 4
✓ CSS selectors, classes (.card) and IDs (#nav)
✓ Google Fonts pairing & typography line-heights
✓ The CSS Box Model: Margin, Border, Padding, Content
✓ Background colors, gradients, and border-radii
🎯
Module Project: Multimedia Tribute & Idol Fan Page

Week 3: Modern CSS Flexbox & Card Layouts

Build 2D multi-column layouts using CSS Flexbox properties: flex-direction, justify-content, align-items, and gap.

Sessions 5 & 6
✓ Display: flex and main vs cross axes
✓ Justify-content and align-items alignments
✓ Flex-wrap and multi-column card grids
✓ Hover transformations (translateY & box-shadow)
🎯
Module Project: EcoPlanet Climate Action Campaign Site

Week 4: Responsive Media Queries & Navigation

Make websites adapt fluidly from wide 4K desktop screens to mobile phone viewports using @media query breakpoints.

Sessions 7 & 8

✓ @media (max-width: 768px) responsive breakpoints
✓ Responsive desktop navigation to mobile drawer layout
✓ Fluid image scaling and percentage widths
