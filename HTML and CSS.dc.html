CURRICULUM SPECIFICATION

5-Module Curriculum

From HTML structure to building and publishing live sites.

Module 1: HTML Structure & Semantics

Sessions 1 & 2

Understand the anatomy of a web page: DOCTYPE, head, body, headings (H1–H6), paragraphs, hyperlinks, image attributes, unordered lists, and modern semantic tags.

  • ✓HTML5 document skeleton & tag syntax
  • ✓Semantic markup: header, nav, main, footer
  • ✓Hyperlinking pages & embedding media
  • ✓Structuring tables & accessible form elements

Module 2: CSS Styling & The Box Model

Sessions 3 & 4

Styling with cascading style sheets! Master CSS selectors (classes, IDs, tags), custom color palettes (Hex, RGB, HSL), Google Fonts typography, and the core CSS Box Model.

  • ✓CSS selectors & external stylesheet linking
  • ✓Typography: Font pairing, line-height & letter-spacing
  • ✓The Box Model: Margin, Border, Padding, Content
  • ✓Border-radius, box-shadows & modern styling

Module 3: Modern Layouts with Flexbox

Sessions 5 & 6

Say goodbye to clunky floats! Master CSS Flexbox: flex directions, justify-content alignment, align-items, flex-wrap, and building multi-column card grids.

  • ✓Flex containers & main vs cross axes
  • ✓Aligning navigation bars & centered hero sections
  • ✓Responsive 3-column card showcases
  • ✓Flex-grow, flex-shrink & gap properties

Module 4: Visual Polish & Mobile Media Queries

Sessions 7 & 8

Add professional micro-animations! Hover scale transforms, smooth color transitions, CSS linear gradients, and responsive @media queries for mobile phones.

  • ✓Pseudo-classes: :hover, :focus, :active
  • ✓Smooth CSS transitions & subtle button lifts
  • ✓Mobile-first media queries (@media (max-width: 768px))
  • ✓Creating a collapsible mobile hamburger menu

Module 5: Build & Publish to the Web

Sessions 9 & 10

Assemble the final multi-page capstone site! Connect navigation links, test responsive layouts across devices, and deploy live using GitHub Pages / Cloudflare.

  • ✓Multi-page site linking (About, Projects, Contact)
  • ✓Meta tags, OpenGraph previews & favicon setup
  • ✓Free live web deployment to custom internet URL
  • ✓Graduation showcase & verified digital certificate
