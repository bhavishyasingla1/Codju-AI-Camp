The Learning Path

1-Month Coding & AI Journey

One comprehensive learning path. Every student learns all 4 domains across dedicated weekly live sessions.

Dedicated Session 1

Scratch Jr: Characters, Motion & Animated Stories

  • Concept: Computational thinking through visual block connecting.
  • Creation: Directing multi-scene holiday stories with character animations.
  • Interaction: Recording custom student voiceovers and touch sound triggers.
🎯 Guaranteed Capstone Outcome

🎬 A 3-Scene Animated Storybook Film created entirely by the student to share with family & school.

Dedicated Session 2

Scratch: Coordinate Physics, Variables & Arcade Games

  • Mechanics: Arrow controls, velocities, jumping, and screen boundary physics.
  • Architecture: Designing dynamic scoreboards, lives counters, and enemy obstacle clones.
  • Polish: Victory celebrations, collision sound effects, and level progression.
🎯 Guaranteed Capstone Outcome

🕹️ A Playable 2D Arcade Game published directly to the Scratch Community for friends to play.

Dedicated Session 3

Python: Real Syntax, Decision Logic & Adventure Games

  • Syntax: Moving beyond blocks to text syntax, data types, inputs, and math operations.
  • Logic: Conditionals (if/elif/else), boolean logic, and dynamic game loops.
  • Execution: Building an interactive text RPG adventure or number battle game on cloud Replit.
🎯 Guaranteed Capstone Outcome

🐍 A Functional Python Game / Script hosted online with public code execution link.

Dedicated Session 4

Building with AI: Prompt Engineering & Web Prototyping

  • Prompting: Mastering conversational AI framing, role prompting, and few-shot reasoning chains.
  • Creation: Generating creative visual art and music using generative AI creator tools.
  • Assembly: Combining AI assets into a functional study assistant bot or web prototype.
🎯 Guaranteed Capstone Outcome

🤖 A Live Custom AI Web Prototype or study assistant app built and demonstrated live.
